## Зачем сохранён этот репозиторий

Лаунчеры до версии **1.0.4 включительно** проверяют обновления по этому адресу. Последний переходный выпуск **1.0.6** обновляет их и переключает последующие проверки на новый репозиторий. Он поддерживает Windows, Linux, Mac Intel и Apple Silicon.

Файлы переходного выпуска совпадают с релизом в [Blockfield/Blockfield-Launcher](https://github.com/Blockfield/Blockfield-Launcher/releases/tag/launcher-v1.0.6) и подписаны прежним ключом обновлений.

Репозиторий оставлен в архиве ради совместимости. Не удаляйте и не переименовывайте его: старым установкам нужен этот endpoint. Новые версии, исходники и обращения пользователей находятся в **[Blockfield/Blockfield-Launcher](https://github.com/Blockfield/Blockfield-Launcher)**.
