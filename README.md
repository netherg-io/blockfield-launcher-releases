# Blockfield Launcher — releases

Binary builds of the private [Blockfield-Launcher](https://github.com/netherg-io/Blockfield-Launcher) repo, published by its CI.
The launcher self-updates from `releases/latest/download/latest.json`.

- Windows: `*-setup.exe` (NSIS) or `*.msi`
- Linux: `*.AppImage`, `*.deb`, `*.rpm`
