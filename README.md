# Blockfield Launcher — legacy update channel

Source code, downloads, issues and future releases have moved to [Blockfield/Blockfield-Launcher](https://github.com/Blockfield/Blockfield-Launcher).

[Download the latest launcher](https://github.com/Blockfield/Blockfield-Launcher/releases/latest).

This repository is retained for installed launchers through version 1.0.4. Its final transition release, **1.0.5**, is signed with the existing updater key and switches future update checks to the new repository.

Do not delete or rename this repository: older installations still need its update endpoint. It is archived after publishing the transition release; no future releases are published here.
